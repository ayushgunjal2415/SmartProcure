# SmartProcure

### Agentic AI-Based Intelligent Procurement Decision Support and Vendor Evaluation System

SmartProcure is an academic project aimed at improving procurement workflows through structured purchase request management, vendor quotation comparison, budget analysis, risk assessment, and AI-assisted recommendations.

## Project Structure

- `frontend/` — React-based user interface and procurement workflows.
- `backend/` — Planned backend APIs and business logic.
- `ai-services/` — Planned AI agents and orchestration services.

## Current Progress

- React and Vite frontend foundation.
- Role-based demonstration interfaces.
- Purchase request creation and review workflows.
- RFQ and quotation management interfaces.
- Quotation comparison and simulated five-agent evaluation.
- Initial order-tracking interface.

The frontend is under active development. AI evaluation results are currently simulated; backend services and actual AI-agent integration are planned for future phases.

## Planned Technology Stack

| Component | Technology |
|---|---|
| Frontend | React, Vite, Tailwind CSS |
| Backend | Java Spring Boot |
| Database | PostgreSQL |
| AI Services | Python, FastAPI |
| Agent Orchestration | LangGraph |
